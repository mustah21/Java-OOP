## Getting Started

### Prerequisites

- Java JDK 17 or 21
- An IDE such as [IntelliJ IDEA](https://www.jetbrains.com/idea/) or [Eclipse](https://www.eclipse.org/)

### Running an Exercise

1. Clone the repository:
   ```bash
   git clone https://github.com/mustah21/Java-OOP.git
   ```
2. Open the project in your IDE.
3. Navigate to the desired exercise folder (e.g., `java1_1`).
4. Run the `Main.java` (or equivalent entry point) file.

## Topics Covered

This repository covers core OOP principles in Java, including:

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
